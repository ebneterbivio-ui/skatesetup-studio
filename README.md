# SkateSetup Studio

Microservice Webapplikation zum Planen und Dokumentieren von Skateboard-Setups.

## Voraussetzungen Zwischenabgabe 1 (15.05.2026)

- React Frontend (Vite) mit allen 3 Seiten: Home, Setup planen, Meine Setups
- Gemeinsamer Navbar und Footer auf allen Seiten
- Service-Module storageService.js und mailService.js als Grundstruktur vorhanden
- Formulare und Backend-Anbindung folgen in Abgabe 2
- Docker / Containerisierung folgt in Abgabe 2
